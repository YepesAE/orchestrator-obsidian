# Components

## Shared Components

| Component | Description |
|-----------|-------------|
| `HcHeader` | Site header with logo, navigation, cart indicator |
| `HcFooter` | Site footer with links, social icons, newsletter |
| `HcLogo` | Cafre brand logo (responsive variants) |
| `HcNav` | Main navigation menu (desktop + mobile hamburger) |
| `HcButton` | Reusable button (variants: primary, secondary, outline, ghost) |
| `HcCard` | Generic card container (image, title, description, action) |
| `HcModal` | Accessible modal with overlay and focus trap |
| `HcSpinner` | Loading spinner for async operations |
| `HcBadge` | Status/category badge (e.g. "New", "Sold out") |
| `HcBreadcrumb` | Breadcrumb navigation trail |
| `HcSearch` | Search input with autocomplete |
| `HcLanguageSwitcher` | EN/ES language toggle |
| `HcImage` | Optimized responsive image with lazy loading |

## Homepage

| Component | Description |
|-----------|-------------|
| `HcHeroBanner` | Full-width hero with Cafre artwork and intro text |
| `HcFeaturedWorks` | Carousel/grid of selected gallery highlights |
| `HcAboutSnippet` | Short bio excerpt linking to About page |
| `HcCTASection` | Call-to-action: visit store, view gallery, contact |

## Gallery

| Component | Description |
|-----------|-------------|
| `HcGalleryGrid` | Responsive masonry grid of artwork thumbnails |
| `HcGalleryFilters` | Filter bar (medium: mural, illustration, canvas; year; tags) |
| `HcGalleryItem` | Single artwork card (image, title, medium, year) |
| `HcLightbox` | Full-screen artwork detail: high-res image, description, dimensions |
| `HcGalleryPagination` | Infinite scroll or page-based navigation |

## Store

| Component | Description |
|-----------|-------------|
| `HcProductList` | Grid of product cards with filtering/sorting |
| `HcProductCard` | Product thumbnail, name, price, add-to-cart |
| `HcProductDetail` | Full product page: images, description, variants, quantity selector |
| `HcCartSidebar` | Slide-out cart drawer showing items and total |
| `HcCartItem` | Single cart line item: image, name, qty, remove |
| `HcCartSummary` | Subtotal, shipping estimate, checkout button |
| `HcCheckoutForm` | Multi-step checkout: shipping, payment, review |
| `HcOrderConfirmation` | Post-purchase success page with order details |

## Blog

| Component | Description |
|-----------|-------------|
| `HcBlogList` | Article listing with pagination |
| `HcBlogCard` | Article preview card (cover image, title, excerpt, date) |
| `HcBlogPost` | Full article view with rich content, author, date |

## Static Pages

| Component | Description |
