## Introduction

Hola Cafre is a single-page application built with Angular, serving as the
official web platform for **Cafre**, an illustrator and muralist based in
Málaga, Spain. The site showcases Cafre's portfolio, sells original artwork and
prints through an integrated store, publishes a blog about creative process and
exhibitions, and provides standard informational pages (about, contact, legal).

### Features at a Glance

| Section | Purpose |
|---------|---------|
| Homepage | Hero banner, featured works, about snippet, CTA |
| Gallery | Grid-based portfolio with filtering, lightbox detail view |
| Store | Product listings, cart, checkout flow |
| Blog | Articles on creative process, exhibitions, murals |
| About / Contact | Artist bio, contact form, social links |
| Legal | Privacy policy, terms of service |

### Current Status

The project is in the **design phase** — visual identity, wireframes, design
system, and component inventory are being defined before development begins.
